# 餘燼地牢 Ember Depths

兩關回合制 roguelike 網頁遊戲。

## 開啟遊戲
1. 解壓縮整個 ZIP（不要只開壓縮檔裡的 HTML）。
2. 使用瀏覽器開啟 index.html，即可離線遊玩。
3. 不需要安裝套件、資料庫或登入網站。

若要使用本機伺服器，在解壓縮後的資料夾執行：
python3 -m http.server 8000
接著在瀏覽器開啟 http://localhost:8000 。

## 操作
- WASD / 方向鍵：移動；朝相鄰敵人移動即可攻擊。
- H：使用藥水恢復 14 HP，會消耗一回合。
- 空白鍵：等待一回合。
- 也可使用畫面下方的方向按鈕。
- 第一層：走到橘色階梯，選擇遺物。
- 第二層：擊敗守門者，走到出口通關。
- 死亡需重新開始，每次地圖重新生成。

## 原始碼結構
- index.html：介面、資訊面板、操作說明。
- style.css：版面、色彩、手機響應式設計。
- game.js：地圖生成、角色狀態、回合戰鬥、敵人尋路、Canvas 繪製。

## 適合報告的實作重點
1. generate()：隨機房間與走廊，確保地圖連通。
2. move() / tick()：玩家行動與敵人回合。
3. nextStep()：BFS 廣度優先搜尋，讓敵人繞牆追擊。
4. choose() / finish()：遺物選擇、勝利與死亡狀態。
5. draw()：用 Canvas 矩形繪製像素風場景與角色。

遊戲使用原生 HTML、CSS、JavaScript，沒有外部素材或套件依賴。
重新整理頁面不保留遊戲進度。
